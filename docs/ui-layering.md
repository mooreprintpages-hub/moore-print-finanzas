# Jerarquía de capas UI

- Sidebar/topbar: 20–30
- Drawer normal: 60
- Drawer secundario: 90
- Modal/formulario: 110

Los modales deben quedar siempre por encima de cualquier drawer para evitar formularios invisibles o inalcanzables en móvil. Los drawers secundarios se usan cuando una acción dentro de un drawer abre otro drawer, como en Compras.
